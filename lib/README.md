# Libraries

Backchat runs three open-source libraries. They are stored here, in this repository, so the app depends on no outside server and runs only code that has been read and published with it.

| File | Library | Version | Licence |
|---|---|---|---|
| `jszip.min.js` | JSZip | 3.10.1 | MIT or GPL-3.0, at your choice ([LICENSE-jszip.md](LICENSE-jszip.md)) |
| `epub.min.js` | epub.js | 0.3.93 | BSD-2-Clause ([LICENSE-epubjs.txt](LICENSE-epubjs.txt)) |
| `minisearch.js` | MiniSearch | 7.2.0 | MIT ([LICENSE-minisearch.txt](LICENSE-minisearch.txt)) |

Each file is the published build from the npm registry, unchanged, checked against the registry's integrity hash.
